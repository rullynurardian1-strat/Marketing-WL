Ringkasan Eksekutif

  • Program berhasil sebagai alat akuisisi PP: 72,4% pemakai (126 user) belum pernah PP sebelum program, termasuk 46 user baru yang transaksi pertamanya di platform langsung memakai PP.
  • Pola pemakaian sangat short-trip: 63,7% perjalanan pulang di hari yang sama atau H+1, dan 76% pemesanan dilakukan 0–3 hari sebelum berangkat.
  • Pendapatan Rp 53,4 jt dihasilkan dengan biaya diskon PP hanya Rp 1,79 jt — rasio pendapatan terhadap biaya diskon ±29,8×.
  • Dari sisi volume, program terbukti menjaga usage PP tetap tinggi di tengah musim yang melandai: rata-rata pax PP/hari selama program (79,3) hanya turun tipis dari 22 hari sebelum program (83,8), padahal baseline Mei (89,4) banyak ditopang rangkaian long weekend yang tidak berulang di Juni.

TEMUAN Program berhasil memaintain volume usage PP di tengah musim landai

Periode program (9–30 Juni) berjalan penuh di bulan yang secara musiman lebih landai — tanpa rangkaian long weekend seperti yang mendorong Mei. Baseline Mei 1–17 (93,3) dan window 18 Mei–8 Jun (83,8) secara natural terdongkrak momentum libur panjang berturut-turut, sehingga wajar berada di level tinggi.

Begitu momentum musiman itu hilang di Juni, rata-rata pax PP/hari selama program tetap terjaga di 79,3 — hanya selisih tipis 4,5 poin (−5,4%) dari window 22 hari sebelum program, jauh lebih landai dibanding potensi penurunan bila mengikuti pola musiman apa adanya. Ini menunjukkan program berperan menahan laju penurunan dan menjaga volume PP tetap tinggi meski kehilangan dukungan musiman.

Ditambah dengan capaian akuisisi — 126 user first-time-PP — program ini berhasil dobel peran: menjaga volume sekaligus memperluas basis user PP baru.

✓ Sisi positif — Akuisisi

126 user first-time-PP (termasuk 46 user baru) berhasil dibawa masuk ke produk PP. Program berperan ganda: menjaga volume di tengah musim landai sekaligus membuka user baru.

⚠ Yang perlu diperhatikan

Booking promo (428 tiket) hanya sebagian dari 1.745 pax PP selama program. Untuk memastikan efek jangka panjang, idealnya bandingkan juga retensi/repeat user promo pasca-program di bulan berikutnya.
