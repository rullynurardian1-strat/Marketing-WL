OKR 1 — Akuisisi FTC
Peningkatan Akuisisi Customer Baru (FTC) menjadi 1.500 Usage dari total Aktivasi Program AOC seluruh operator aktif, per 30 September 2026
1 Jul – 30 Sep 2026
Menjadi mesin akuisisi FTC yang kontribusinya terukur jelas pada seluruh portfolio operator
📊 Baseline
FTC Usage Q2 2026 — ~1.000 usage, ~10 operator aktif (+50%)
✅ Evidence
Laporan bulanan DA (Dashboard Performance Operator) — breakdown FTC ter-atribusi campaign vs total FTC, dipakai untuk grading akhir Q3
KR 1.1
Capai 15 Aktivasi Program AOC di operator aktif, per 30 September 2026
Baseline: 10 Program AOC di 10 Operator (Q2 2026)
1.1.1SMINDIVIDU
15 program aktivasi akuisisi AOC live, tersebar di seluruh operator aktif.
Evidence: campaign brief + laporan performance per program
1.1.2DAINDIVIDU
Laporan FTC total vs FTC ter-atribusi campaign per operator, terbit mingguan (≥12 laporan sepanjang Q3).
Evidence: link report mingguan
KR 1.2
Menurunkan gap usage rate program AOC dari 43% menjadi 27% (usage rate naik dari 57% → 73%), per 30 September 2026
Baseline: Gap usage rate Q2 2026 = 43% · Usage rate aktual = 56,72% (1.021 dari 1.800 kuota)
1.2.1SMINDIVIDU
Setiap program AOC memiliki mekanisme promosi aktif (reminder, push notif, komunikasi langsung ke user) selama periode berjalan untuk mendorong redemption.
Evidence: dokumentasi mekanisme promosi per program + laporan redemption rate bulanan
1.2.2DesignerINDIVIDU
Design Kit (1 Pop-up + 1 Banner In-App + 5 Banner in Artikel) untuk 15 operator diproduksi & dioptimasi — CTA jelas, konsisten dengan identitas masing-masing operator.
Evidence: link asset kit per operator
1.2.3DesignerINDIVIDU
Conversion rate Design Kit mencapai 40% secara keseluruhan program AOC (Baseline Q2 2026: 34,67%).
Evidence: laporan CTR/konversi per asset
1.2.4DAINDIVIDU
Laporan gap usage rate per program AOC, update bulanan (Juli, Agustus, September), dengan early warning flag jika ada program di bawah 50% di pertengahan periode.
Evidence: link report bulanan + log early warning
1.2.5SEO TechSUPPORTING
Tap-in CMS (popup/banner in-app) aktif terpasang untuk setiap program AOC sesuai jadwal live.
Evidence: log konfigurasi CMS per program
KR 1.3
Capai 5 Operator Graduate Stage — kemandirian aktivasi AOC (cost-share 50:50 → 100% mandiri operator), per 30 September 2026
Baseline: 0% Fase 2 pada Q2 2026. Kandidat Graduation: Kruzz (96,5%), Sumber Jaya (100%), Sabila Shuttle (99,33%), Gracias (100%) + 1 kandidat dari Sustain & Push Q3
1.3.1SMINDIVIDU
Tawarkan AOC ke 15 operator; dorong 5 operator naik Fase 1 → Fase 2 (4 kandidat Q2 + 1 dari Sustain & Push Q3).
Evidence: dokumen kesepakatan fase per operator (target 5 dokumen)
1.3.2DAINDIVIDU
Laporan % kemandirian aktivasi & beban budget FDL per FTC per operator, terbit bulanan (3 laporan).
Evidence: link report bulanan

3.2.4DAINDIVIDU
Laporan usage rate per program retensi, update bulanan (target: ≥50% per program per laporan).

5 digital kit tersedia untuk 5 program aktivasi retensi, SLA produksi sesuai jadwal per program, per 30 September 2026
3.3.1DesignerSUPPORTING
5 asset kit selesai sesuai SLA, masing-masing untuk 1 program retensi (banner in-app, banner in artikel, feed/reels, pop-up, Tent card A5, atau X Banner).
Evidence: link folder asset final per program (5 folder)
3.3.2DesignerINDIVIDU
1 library template asset retensi reusable dibangun dari 5 kit yang diproduksi, dipakai ulang 2 kali oleh SM.
Evidence: link library + log penggunaan

Brief program diberikan ke Designer minimal 7 hari sebelum tanggal live.
Evidence: timestamp brief masuk vs tanggal live per program
